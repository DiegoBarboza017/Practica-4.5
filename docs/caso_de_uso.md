# Plantilla de caso de uso

## 1) Usuario principal
- ¿Quién usará el programa?

## 2) Contexto del usuario
- ¿En qué escenario lo usará?
- ¿Con qué frecuencia?

## 3) Situación inicial
- ¿Qué tiene el usuario antes de ejecutar tu solución?

## 4) Flujo principal (paso a paso)
1. 
2. 
3. 
4. 

## 5) Flujo alternativo
- ¿Qué pasa si cambia una condición?
- Describe un camino alterno breve.

## 6) Errores posibles
- Entrada inválida.
- Archivo inexistente.
- Formato incorrecto.
- Otros errores esperados.

## 7) Resultado esperado
- ¿Qué obtiene el usuario al final?

## 8) Ejemplo de uso en terminal
```bash
# Ejemplo genérico
./scripts/run.sh
```

## 9) Justificación de viabilidad
Explica por qué este caso de uso es pequeño y viable para una práctica corta en GitHub Classroom.
