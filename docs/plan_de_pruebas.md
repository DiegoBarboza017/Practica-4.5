# Plantilla de plan de pruebas

## 1) Objetivo del plan de pruebas
Describe qué vas a validar y por qué.

## 2) Casos de prueba
| ID | Escenario | Entrada | Resultado esperado | Resultado obtenido | Estado |
|----|-----------|---------|--------------------|--------------------|--------|
| CP-01 | Ejecución básica |  |  |  | Pendiente |
| CP-02 | Entrada inválida |  |  |  | Pendiente |

## 3) Pruebas manuales
- Lista de pasos para validar el funcionamiento en terminal.

## 4) Pruebas con errores
- Qué errores forzarás y cómo validarás su manejo.

## 5) Pruebas mínimas por lenguaje
- ARM64: ejecución de rutina mínima con entrada/salida básica.
- C: compilación y ejecución sin warnings críticos.
- Python: ejecución de script principal sin dependencias externas.
- Bash: permisos de ejecución y manejo básico de argumentos.

## 6) Criterios de término
Marca la práctica como terminada cuando:
- El flujo principal funciona.
- Hay evidencia de pruebas mínimas.
- La documentación está completa y coherente.
- El alcance se mantuvo pequeño.
