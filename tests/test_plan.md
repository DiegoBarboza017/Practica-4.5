# Checklist breve de pruebas y entrega

## 1) Pruebas mínimas
- [ ] El programa corre en el flujo principal.
- [ ] Se probó al menos una entrada inválida.
- [ ] Se validó al menos un caso límite.

## 2) Documentación
- [ ] `docs/propuesta.md` está completo.
- [ ] `docs/caso_de_uso.md` está completo.
- [ ] `docs/plan_de_pruebas.md` tiene casos definidos.

## 3) Ejecución
- [ ] `scripts/run.sh` funciona en tu entorno.
- [ ] Existe un archivo principal en `src/`.
- [ ] No se usan dependencias complejas.

## 4) Entrega final
- [ ] El alcance se mantuvo pequeño y viable.
- [ ] La solución está explicada de forma clara.
- [ ] El repositorio está ordenado y entendible.
